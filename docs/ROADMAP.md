## M1 播放完善 🟡

已完成：

- ✅ 播放进度上报（Start / 每 10 秒 Progress / 暂停继续 / Stopped），串行发送保证顺序；转码结束时清理服务器转码进程
- ✅ 播放结束立即上报 Stopped，服务器据此标记已看；结束后拖动进度可继续播放（修复「看完无法重播」）
- ✅ 字幕：文本字幕统一由服务器转 WebVTT、客户端渲染（直放 / 转码通用，不触发转码）；图形字幕（PGS 等）选择后由服务器烧录；字幕延迟调整
- ✅ 音轨：直放时本地切换，转码时按音轨重新选流并从当前位置继续
- ✅ 跳过片头 / 回顾（Jellyfin MediaSegments、Emby 章节标记），可设置自动跳过
- ✅ 下一集：片尾标记或结束前 30 秒弹出卡片，10 秒倒计时自动播放（暂停时冻结）
- ✅ 锁屏 / 控制中心「正在播放」与远程控制
- ✅ 播放设置页：快进快退秒数、长按倍速、手势开关、字幕字号与位置
- ✅ 内核报错时显示原因并支持「从当前位置重试」

已修复的关键问题（记录根因，避免回归）：

- 登录 401：Emby 请求体不能同时带明文 `Password`（旧 SHA1 字段），只发 `Pw`
- ATS：`NSAllowsArbitraryLoads` 不能与 `NSAllowsLocalNetworking` 等键并存，否则被系统忽略
- 播放中闪退：MediaPlayer 在后台队列回调封面闭包，闭包不能被推断为 `@MainActor`
- 详情页被撑宽：`scaledToFill` 图片必须放进固定尺寸占位的 overlay

待验收：

- 🟡 实机验证进度上报、已看标记与继续观看进度
- 🟡 Emby 转码流在接近片尾处续播偶发 `CoreMediaErrorDomain -16046`（已有重试入口，根因待查：疑与 `StartTimeTicks` 生成的 HLS 偏移有关）

- ✅ 单集 / 电影：播放源卡片（版本 / 音轨 / 字幕预选，随播放请求生效）、「更多来自本季」、带缩略图的章节
- ✅ 演职人员、类似作品、外部链接（豆瓣 / IMDb / TMDB / TheTVDB / Bangumi）
- ✅ 媒体信息：视频 / 音频 / 字幕流卡片、文件路径、容器、大小、添加时间
- ⬜ 详情页状态栏改为浅色（深色头图上目前为黑字）
- ⬜ 预告片与花絮（LocalTrailers / SpecialFeatures / RemoteTrailers）

播放器界面 ⬜（参考 SenPlayer）：

- ⬜ 顶部：关闭、标题、AirPlay、画中画、章节跳转、倍速
- ⬜ 拖动进度时顶部居中显示「当前 / 总时长」、迷你进度条与偏移量（如 `08:30 / 24:27  +02:12`）
- ⬜ 底部次级按钮行：播放信息（直放 / 转码、编码、码率）、音轨、字幕、画面比例、更多
- ⬜ 底部传输行：锁定 | 上一集、播放 / 暂停、下一集 | 剧集列表（当前季单集面板）
- ⬜ **拖动进度条时预览画面**：本地实现，不依赖服务器下发的 trickplay / BIF 预览图。方案：另建只解码不渲染的 `AVAssetImageGenerator`（转码 HLS 时用独立低码率流），按拖动位置节流抽取关键帧并缓存；MPV 内核接入后改用其独立解码实例
- ⬜ **音轨 / 字幕显示中文信息**：在服务器原始标题下补充中文语言名，例如 `Japanese AC3 stereo (默认) 48 kHz 192 kbps` 下方显示「日语」，`Chinese AAC stereo` 显示「国语」，`Chinese Simplified (ASS)` 显示「简体中文」、`Chinese Traditional` 显示「繁体中文」；同时展示采样率、码率与默认 / 强制 / 外挂标记。详情页播放源卡片与播放器内菜单共用同一套格式化
- ⬜ 截图、画面旋转
